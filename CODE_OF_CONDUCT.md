# Code de conduite

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : sois accueillant et respectueux, critique les idées et pas les personnes, et accepte les désaccords avec
bienveillance. Le harcèlement, les insultes et les attaques personnelles ne sont pas tolérés, dans les issues, les pull
requests et partout où le projet est représenté.

Un comportement problématique se signale en privé par
[Security › Report a vulnerability](https://github.com/tomonchain/dexlane/security/advisories/new), ou en écrivant à la
personne qui maintient le projet. Chaque signalement est traité avec discrétion.
